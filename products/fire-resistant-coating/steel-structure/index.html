No.01 · 에어로젤 방화도료

철골 구조용 에어로젤 내화도료

Aerogel Fire-Resistant Coating for Steel Structures

도막으로 철골 부재를 감싸 최대 180분(제조사 시험 기준)의 내화 성능을 제공하는 철골 구조용 내화도료입니다.

내화 90~180분A급
견적·샘플 문의 TDS 받기
제조원숴싱 신소재(중국)공급EXOSKIN
Features

제품 특징

방화·방습·내식성, 내열성·내강산성

높은 경도와 부착강도, 우수한 인성

경량, 분말화 없음

중금속·포름알데히드·벤젠·자일렌 등 유해물질 방출 없음

Benefits

이런 점이 좋습니다

  1. 도막으로 철골 부재를 보호하며 최대 180분의 내화 성능 제공
  2. 부식성·산성 환경(산업 설비)에도 적용 가능
  3. 색상 조절이 가능하여 노출 철골의 마감재로도 사용 가능
  4. 제조사 수출 실적: 캐나다, 한국, 인도네시아, 필리핀, 태국
Applications

적용 공간

건축물철골 기둥·보(철골조 건축물)건축물샌드위치 패널 공장·창고산업·공장 설비저장탱크산업·공장 설비산업 설비 철골 구조전력·통신데이터센터
Specifications

기술 사양

내화시간90~180분

시험 기준제조사 시험 기준(중국 GB 등) · 성적서 번호는 수령 후 기재
제조원 / 원산지숴싱 신소재 / 중국
